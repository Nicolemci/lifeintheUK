# App Store Connect — Header & Search Results assets

Upload under **iOS App Version → Product Page Information → Header and Search Results**.

Images are **RGB PNG with no alpha** (Apple requirement).

| File | Size | Use |
|---|---|---|
| `header-search-universal-5244x2950.png` | 5244×2950 (16:9) | **Easiest:** one PNG for both Header and Search Results |
| `header-3840x1646.png` | 3840×1646 (21:9) | Header only |
| `search-results-3840x2560.png` | 3840×2560 (3:2) | Search Results only |

## Recommended upload

1. Open the **Header** tab → upload `header-search-universal-5244x2950.png`  
   **or** `header-3840x1646.png`.
2. Open **Search Results** → upload the same universal file  
   **or** `search-results-3840x2560.png`.
3. Use **Preview** in App Store Connect to check cropping.
4. Copy text from `APP_STORE_COPY.md` into Promotional Text and Description.

These creative assets are optional and only appear on newer App Store layouts; they do not block review if left empty.
